## Coding & Planning Standards

### Planning

- All generated plans must include **code snippets** for all proposed changes.
- Plans must include specific **file references**.

### Naming Conventions

- **Private Members**: Private and protected class members must be prefixed with an underscore (e.g., `private _value`).

### Formatting

- Indentation: 4 spaces.
- Enforced by Prettier/ESLint.
